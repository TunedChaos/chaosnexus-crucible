# ChaosNexus Crucible

Local LLM **interface** for ChaosNexus (Hugging Face Candle / Colibri backends + MCP client toward Anvil). This is the runtime bridge to talk to models, not the model weights or the Tuned training stack.

> **Status:** early / experimental. Alpha-launch polyrepo is public-facing; APIs and backends may still change.
