# ChaosNexus Crucible

Local LLM **interface** for ChaosNexus (Hugging Face Candle / Colibri backends + MCP client toward Anvil). This is the runtime bridge to talk to models, not the model weights or the Tuned training stack.

> **Status:** early / experimental. Alpha-launch polyrepo is public-facing; APIs and backends may still change.

- **Docs:** [chaosnexus.ai/guide/chaosnexus-crucible/about](https://chaosnexus.ai/guide/chaosnexus-crucible/about)
- **Contribute:** [github.com/TunedChaos/chaosnexus-crucible](https://github.com/TunedChaos/chaosnexus-crucible)
- **Support:** [Tuned Chaos supporters](https://tunedchaos.com/supporters/) or [GitHub Sponsors](https://github.com/sponsors/TunedChaos)
